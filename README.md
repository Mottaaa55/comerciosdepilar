# Comercios de Pilar

Guía de comercios locales del partido de Pilar, Buenos Aires. Sitio en Next.js a partir de la guía HTML original.

El sitio se exporta como HTML estático (`out/`) y se sirve con Bun.

```bash
bun install
bun run build
bun run start
```

Abrí [http://localhost:3000](http://localhost:3000).
